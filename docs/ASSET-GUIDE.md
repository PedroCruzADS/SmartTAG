# Guia de assets

## Estrutura recomendada
```
assets/<slug-produto>/
  product/
  lifestyle/
  logo/
  fonts/
  audio/
  references/
```

## Preferências
- PNG/WebP com transparência para recortes;
- imagens em resolução alta;
- vídeos sem overlays queimados quando possível;
- SVG/PNG oficial para logo;
- fontes oficiais em arquivo;
- referências separadas dos assets utilizáveis.

## Referência não é asset
Arquivos em `references/` servem para direção visual. Não copiar logos, textos, produtos ou elementos proprietários da referência para a peça.

## Produto
Nunca usar geração de imagem para reconstruir o produto quando existe fotografia real fornecida.
