# Matriz de criativos para performance

A função do lab não é gerar dezenas de cópias cosméticas. Cada variação deve testar uma hipótese.

## Eixos úteis
- Hook: produto / oferta / dor-benefício / demonstração.
- Enquadramento: hero / detalhe / lifestyle disponível.
- Mensagem: benefício principal / condição / novidade.
- CTA: curto / descritivo.
- Ritmo: direto / progressivo.

## Lote inicial recomendado
1. Master: produto + proposta principal.
2. Variação hook produto.
3. Variação hook oferta.
4. Variação benefício comprovado.
5. Resize dos vencedores para placements necessários.

## Registro
Em `notes.md`, registrar:
- hipótese;
- variável alterada;
- elementos mantidos;
- versão fonte.

Evitar mudar hook, layout, copy, duração e CTA todos ao mesmo tempo quando o objetivo for aprender com performance.
