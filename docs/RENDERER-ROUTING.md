# Renderer routing

O Lab é renderer-agnostic. O objetivo é o melhor criativo editável e verificável, não fidelidade a uma única ferramenta.

## Tesseract
Prefira para footage, compositing, máscaras, retiming, edição e acabamento quando a instalação local estiver disponível.

## Remotion
Prefira para React, tipografia/layout programático, variantes em escala, templates e criativos data-driven. Use as Agent Skills oficiais quando instaladas.

## HyperFrames
Prefira para motion graphics HTML/CSS/GSAP, composição determinística, iteração rápida por agente, snapshots/comparação e render programático.

## Híbrido
É permitido gerar elementos em Remotion/HyperFrames e finalizar no Tesseract, ou o inverso, quando isso reduzir trabalho e preservar qualidade.

## 21st.dev
Opcional. Use para UI realista quando o vídeo contém interfaces/cards/buttons e não há componente real da marca/produto disponível. Nunca substitua screenshot/UI real por UI inventada quando fidelidade ao produto for requisito.

## Regra
Antes de produzir, registre em `direction.md`: renderer escolhido, motivo, fallback e quais etapas serão usadas para QA.
