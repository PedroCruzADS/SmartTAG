# Playbook de mídia paga

## Objetivo do criativo
Capturar atenção, tornar o produto reconhecível e comunicar uma razão concreta para clicar/comprar.

## Estrutura curta sugerida
- 0–1,5s: hook;
- 1,5–6s: produto/benefício;
- fechamento: oferta + CTA + marca.

Isto é um ponto de partida, não uma regra fixa.

## Produto primeiro
Para e-commerce, preservar:
- aparência;
- proporção;
- cor;
- acessórios inclusos;
- detalhes visíveis;
- relação correta entre variantes/SKUs.

## Performance
Ao gerar variações, mudar uma hipótese de forma deliberada. Não criar versões aleatórias só para aumentar volume.

## Placements
O agente deve confirmar especificações atuais da plataforma quando elas forem materialmente relevantes. Não assumir que dimensões, safe areas ou limites de anúncios são permanentes.

## Landing page
A promessa criativa deve ser compatível com a página de destino e com o snapshot comercial usado.
