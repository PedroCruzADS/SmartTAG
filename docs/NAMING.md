# Convenção de nomes

## Projeto
`YYYYMMDD_produto_objetivo_formato_vNN`

Exemplo:
`20260923_esteira-b55_black-november_9x16_v01`

## Arquivos
- `Project.tsrct`
- `Project.mp4`
- `Previews/Filmstrip.png`
- `brief.md`
- `offer.json`
- `notes.md`

## Variações
Use sufixos:
- `_hook-a`
- `_hook-b`
- `_cta-a`
- `_price-focus`
- `_benefit-focus`

Evite nomes como `final-final2.mp4`.
